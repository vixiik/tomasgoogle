# Citace a zdroje

## Použité zdroje

- Google. „Google Search.“ https://www.google.com/ — vyhledávací služba, na kterou odkazují formuláře projektu.
- Google Fonts. „Google Sans.“ https://fonts.google.com/specimen/Google+Sans — písmo použité pro logo.
- World Wide Web Consortium (W3C). „Nu Html Checker.“ https://validator.w3.org/nu/ — oficiální HTML validátor a jeho ikona: https://validator.w3.org/nu/icon.png.
- W3C CSS Validation Service. „Valid CSS“ badge. https://jigsaw.w3.org/css-validator/ — oficiální CSS validátor a jeho badge: https://jigsaw.w3.org/css-validator/images/vcss-blue.

> pres github se mi neukazuji ikony sprav to a dej tam officialni ikony tech validatoru
